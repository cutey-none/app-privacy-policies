# 应用隐私声明

集中维护各应用公开的隐私政策，并通过 GitHub Pages 提供无需登录的访问网址。

## 已发布应用

| 应用 | 隐私政策 | 源文件 |
| --- | --- | --- |
| 息刻（BreathTick） | https://cutey-none.github.io/app-privacy-policies/breathtick/ | [breathtick/index.html](breathtick/index.html) |

## 添加或更新政策

每个应用使用独立目录和 `index.html` 文件。新增应用时同步更新根目录的 `index.html` 和本表。

根据应用实际的数据处理方式维护政策，更新正文中的日期和适用版本。提交前检查公开内容，确认其中的联系方式可以公开。发布完成后验证网址无需登录即可访问，再用于应用商店。

GitHub Pages 从 `main` 分支根目录发布。政策历史可以通过 Git 提交记录查询。
